# Native Windows agenda — approved design

Build a C#/WinUI 3 desktop flyout with real acrylic and Windows controls. A roughly 392-DIP surface contains the local clock, a collapsible month, week numbers, a selected-day agenda, calendar selection, quick event creation, event details, and settings. Follow system theme, accent, regional formats, first weekday, week numbering rule, and custom user overrides. Week numbers default on; ISO override forces Monday and the first-four-day week. Date-only calculations handle week-year boundaries. Settings changes refresh the presentation.

Use a notification-area icon as reliable activation and an opt-in, fail-open compatibility layer for taskbar-clock clicks. Do not inject into Explorer. Preserve Win+N, clock right-click, and outside-click/Escape dismissal. Handle multiple monitors, DPI, Explorer restart, suspend/resume, and window focus. Hide the flyout rather than terminating the tray process; expose Exit explicitly.

Use Windows WAM/MSAL with the app's own public client registration and delegated Graph calendar permissions. Offer native Windows account selection, calendar selection, refresh, create, details, and sign-out. Reuse supported Windows identities, not another application's tokens or private cache. A registration client ID is configuration, never a borrowed ID or embedded secret. Link Windows account settings. Auth cancellation, missing configuration, no accounts, denied permissions, offline/stale cache, read-only calendars, and save failures must be visible and truthful. Never present example events as live data. Google and other providers require their own authorization and are not promised through Windows account discovery.

Cache events locally using user-bound Windows protection. Only show confirmed successful writes; preserve drafts on failure. Expand recurring events using calendarView and follow Graph paging. Time zones, all-day dates, and event identity must survive cache round trips. Keep provider, UI, and shell boundaries independent.

First implementation is a runnable native application with Microsoft integration and explicit setup requirements. Produce build/run commands, deployment instructions and actual validation evidence. Ship an unpackaged development build for immediate review, plus an MSIX packaging route for distribution; no silent certificate installation, autostart registration, or publishing.
