# Agenda app artwork

`agenda-master.png` was generated with the built-in image-generation tool on 2026-09-10. It is the transparent color master for the executable icon and package logos. `scripts/create-assets.ps1` resizes it into the required PNG and multi-resolution ICO assets. The notification-area icons retain their separate pixel-aligned monochrome drawing.

## Generation prompt

Use case: logo-brand. Create a single finished application icon for Agenda, a native Windows 11 calendar/agenda app. Professional Fluent-style Windows app identity, polished blue calendar with a gently layered paper face, restrained cyan-to-azure depth, soft beveled edge and a subtle folded paper corner. Front-facing, nearly flat, strong recognizable calendar silhouette, two simple binding tabs, minimal agenda markings (two or three clean horizontal strokes and one small blue date tile). Premium quiet productivity aesthetic; not toy-like, no glass blob, no excessive gloss, no heavy perspective. No text, no numbers, no letters, no watermark, no surrounding rounded-square app tile, no scene or mockup. One icon only, centered, fills about 88% of a square 1024x1024 canvas with equal padding. Isolated on a genuinely transparent alpha background, preserve clean edges; no checkerboard painted into the image. Must read clearly at 32 and 48 pixels. This is the colored app logo, not the monochrome system tray glyph.

The original transparent output was selected. Subsequent cleanup variants introduced an opaque background and were discarded.
